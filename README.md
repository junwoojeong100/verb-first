# Verb First

기본동사를 먼저 꺼내는 영어 말하기 훈련 웹앱입니다. 제공된 영어 학습 PDF 8종을 바탕으로 핵심동사, 회화 패턴, 구동사, 업무 회의 문장을 하나의 반복 학습 흐름으로 구성했습니다.

## 실행

```bash
npm install
npm run dev
```

## 주요 기능

- 30개 핵심 기본동사 심화 카드, 동사별 원어민 실전 회화 용법 10개, 18개 문장 틀
- 기본동사 100가지 쓰임 + 구동사 100개 통합 검색
- 영어 회의 원문 100개 + 응용 표현 200개 전체 수록
- 16개 회의 상황과 원문·응용을 묶은 30일 집중 코스
- 첨부 워크북 4권의 대표문장 400개와 명확한 한국어 원문, 예문 1,200개, 스몰토크 400개, TIP 400개
- Native Speaking Blueprint의 상황 주어, 의미 단위, 내 이야기 변환 훈련
- 즉답 리콜, 문장 조립, 동사 선택, 3회 섀도잉
- 기억 간격에 따른 자동 복습 큐
- 나만의 문장 저장 및 반복 연습
- 학습 스트릭, 활동 히트맵, 동사별 숙련도
- 브라우저 음성 합성, 다크 모드, 로컬 백업/복원
- `localStorage` 기반 기록 저장과 설치형 PWA 지원

프로덕션 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`로 실행합니다.
학습 데이터의 누락·중복 검사는 `npm run validate:content`로 실행합니다.
